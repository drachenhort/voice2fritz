# DTMF Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing dialpad buttons send DTMF tones during an active call, instead of editing the number field — with a subtle visual highlight while in that mode.

**Architecture:** One new method on `SipEngine` wrapping pjsua2's `Call.dialDtmf()`; `MainWindow._on_digit_clicked` branches on whether a call is active; dialpad buttons get a dynamic `dtmfMode` property toggled alongside the existing hangup/mute enable-state changes, with a new QSS rule.

**Tech Stack:** Python, PySide6, pjsua2 (existing stack, no new dependencies).

## Global Constraints

- No active call → digit buttons append to `number_edit` (unchanged v1 behavior).
- Active call → digit buttons send DTMF via `SipEngine.send_dtmf(call, digit)`, and do NOT modify `number_edit`.
- Dialpad buttons show a subtle blue-border highlight while in DTMF mode (dynamic property `dtmfMode`, set/unset alongside the existing `hangup_button`/`mute_button` enable-state toggles).
- No automated test for `SipEngine.send_dtmf` itself (pjsua2 unavailable in the dev sandbox) — verified via `py_compile` and a manual real-call test, consistent with the rest of `sip_engine.py`.

def test_dialpad_button_sends_dtmf_during_active_call(qtbot):
    engine = FakeSipEngine()
    window = MainWindow(engine)
    qtbot.addWidget(window)

    window.number_edit.setText("01234567")
    window.call_button.click()
    active_call = window._active_call
    window.number_edit.clear()

    window.digit_buttons["5"].click()

    assert engine.dtmf_sent == [(active_call, "5")]
    assert window.number_edit.text() == ""


def test_dialpad_button_appends_to_field_after_call_ends(qtbot):
    engine = FakeSipEngine()

    qtbot.addWidget(window)

    window.call_button.click()

    assert window.number_edit.text() == "9"


def test_digit_buttons_get_dtmf_mode_property_during_active_call(qtbot):

    qtbot.addWidget(window)

    assert window.digit_buttons["1"].property("dtmfMode") in (None, False)

    window.number_edit.setText("01234567")
    window.call_button.click()

    assert window.digit_buttons["1"].property("dtmfMode") is True
