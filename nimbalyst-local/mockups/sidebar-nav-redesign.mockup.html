Sidebar navigation redesign — replaces the modal Contacts/Settings dialogs

Today, Contacts and Settings are separate QDialog windows opened from nav buttons (ContactsDialog, SettingsDialog) — the dialpad restyle plan explicitly left this out of scope. This mockup folds all four views into one window behind a persistent left icon rail, closer to your "Fritz!Phone Linux" reference image from 2026-08-04, but scoped down: no FRITZ!Box device-status/DECT/answering-machine panel, no Hold/Transfer/Video — those are real unbuilt features, not layout, and would reintroduce the generic-SIP-client complexity you've asked to avoid. They're sketched as a disabled strip at the bottom of each screen only so the direction is visible, not proposed as scope.
